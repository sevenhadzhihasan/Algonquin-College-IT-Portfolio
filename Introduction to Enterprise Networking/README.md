# Introduction to Enterprise Networking

### 🛠️ Lab Hardware & Devices
The following Cisco routing and switching platforms are utilized throughout the labs in this course:

| Device Type | Model / Series | Description & Usage |
| :--- | :--- | :--- |
| **Router** | Cisco ISR 4331 | Integrated Services Router used for edge routing, WAN simulation, and OSPF routing configurations. |
| **Switch** | Cisco Catalyst 3850 | Layer 3 stackable enterprise switch used for advanced core/distribution switching, switching topologies, and VLAN routing. *(Fitted with a C3850-NM-BLANK slot cover).* |

### 💻 Simulation Software & Environment Versions
The topologies are built, simulated, and verified using the following platform versions:

| Software Platform | Version / Build | Purpose |
| :--- | :--- | :--- |
| **Cisco Packet Tracer** | `9.0.0.0810` | IoT smart solutions, basic routing/switching, and lightweight lab simulations. |
| **Cisco Modeling Labs (CML2)** | `2.10.0+build.13` | Advanced enterprise network simulations, multi-node topologies, and heavy IOS routing labs. |
